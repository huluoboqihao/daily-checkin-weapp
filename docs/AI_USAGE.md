# AI 使用说明

## 一、运行时 AI（作品的一部分）

| 能力 | 实现 | 是否联网 |
|---|---|---|
| 习惯图标建议 | 自训练 9 类逻辑回归；ONNX 推理 → JS 前向 → 关键词规则 | 否 |
| AI 洞察 | 近 4 周记录的确定性统计：断签风险、最弱习惯、最佳星期、今日过载、下一件事 | 否 |
| 习惯生成 | 云函数 `genHabits` 调 DeepSeek；未配置时本地规则 | 配置后联网 |
| 待办解析 | 云函数 `parseTasks` 调 DeepSeek；未配置时本地规则 | 配置后联网 |
| AI 指令 / 教练 | 云函数 `aiAgent` / `wx.cloud.extend.AI`；未配置时本地教练 | 配置后联网 |

未配置云环境时，界面显示「本地规则」「本地示例」，不把兜底结果说成模型输出。

## 二、开发期 AI

- 使用 DeepSeek 辅助代码阅读、规则核对、文档与材料初稿；
- 团队对生成内容做人工复核、修改和测试，不以 AI 生成作为自主知识产权依据；
- 具体提示词与逐条修改记录未完整留存，这是当前披露的边界。

## 三、端侧模型

- 任务：习惯名称 → 9 类图标之一；
- 特征：单字 + 二字 n-gram，FNV-1a 哈希到 256 维，L2 归一化；
- 模型：256×9 权重 + 9 维偏置，ONNX 文件约 9.2 KB；
- 训练数据：合成的 536 条中文习惯短语，同分布留出集准确率 1.0；真实长尾表达仍需更多数据；
- 推理顺序：`wx.createInferenceSession` → 同一套权重的 JS 前向 → 关键词规则。

## 四、AI 生成内容核查

- 作品界面中的示例打卡记录为预置演示数据，界面已注明；
- 海报、报告、PPT 中的数字来自测试输出或代码统计，不使用模型生成数字；
- 不含第三方受版权保护的图片、字体或数据集。
